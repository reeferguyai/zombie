⚙️ 2. BLOODLUST + CANNABIS SYSTEM
Here’s the core gameplay effect logic:
🎮 HUD:
🩸 Bloodlust Meter (fills over time)
🪴 Weed Gauge (affects sanity, health, and bloodlust)
♻️ Decay Meter (long-term wear-down unless weed is used)

[Combat Buffs from Weed Use]

🧠 Pseudo Code Example (Godot-style GDScript):
var bloodlust = 0
var decay = 0
var highness = 0
var max_high = 100
var is_high = false

func _process(delta):
    # Bloodlust rises slowly
    bloodlust += delta * 0.25
    decay += delta * 0.05

    # Highness decays over time
    if highness > 0:
        highness -= delta * 1
        is_high = true
    else:
        is_high = false

    # Weed effect on bloodlust
    if is_high:
        bloodlust -= delta * 0.75  # slows down bloodlust

func smoke_weed(strain_strength):
    highness = clamp(highness + strain_strength, 0, max_high)
    decay -= strain_strength * 0.5  # slow the rot too

var visibility_level = 100  # 0 = invisible, 100 = fully visible
